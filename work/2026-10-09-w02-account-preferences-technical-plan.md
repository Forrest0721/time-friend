> 依据：[Web 功能地图](dida-web-capability-map.md)、[Web 分阶段开发计划](web-development-plan.md)。

## 1. 为什么今天先做 W02

开发计划要求先完成 M0，再进入任务、习惯和专注增量。当前仓库已经具备 Better Auth 会话、用户隔离、账号导出/删除、任务与专注的真实 API，但账号偏好仍有三个直接缺口：

1. `users.week_starts_on` 被数据库约束为只能是周一，无法表达真实用户偏好；
2. 时区只在注册时默认成 `Asia/Shanghai`，没有经过验证的修改命令和 Web 入口；
3. Web 的设置按钮没有可用页面，账号导出、删除及日期偏好散落或不可达。

时区和周起始日是 W08 日期与时间、W22–W26 习惯、W31 统计的共同前置。先补 W02 可以避免后续各模块各自解释“今天”“本周”和本地日期。

今天不实现外观、提醒、智能清单显隐和一级功能模块开关。它们在滴答设置中属于相邻分类，但分别依赖 W01、W10、W11、W35；本轮只记录其信息架构，不创建无真实能力的开关。

### 2.3 日期与时间

日期与时间页按三个卡片分组：

1. 时间格式、日期格式、每周开始于；

### 2.5 账户与危险操作

账户页连续展示身份、登录方式、登录设备/API、备份恢复和账号管理；删除账号位于最底部。打开删除账号后，二级对话框要求：

- 输入当前密码；
- 明确确认数据会全部删除；
- 再次确认删除意图；
- 最后点击“确认”。

见时已有服务端“精确输入 `DELETE` + 立即撤销会话 + 后台擦除”语义。本轮保留该后端契约，在设置页用独立危险区和二次确认呈现，不降低现有安全门槛。

## 4. 数据与领域设计

### 4.1 用户偏好字段

保留 `users.timezone` 和 `users.week_starts_on`，新增 `settings_revision`：

| 字段 | 规则 |
|---|---|
| `timezone` | 非空 IANA time zone；服务端用 `Intl.DateTimeFormat` 验证 |
| `week_starts_on` | `0..6`，`0=周日`、`1=周一`，与 JavaScript/Temporal weekday 映射在适配层显式转换 |
| `settings_revision` | 从 1 开始，每次偏好写入加 1 |

迁移删除旧的“只能等于 1”约束，改为 `BETWEEN 0 AND 6`。历史用户值保持为 1，无数据改写。

### 4.2 领域命令

`UserPreferenceService.updateDateTimePreferences` 接收：

```ts
{
  timezone?: string;
  weekStartsOn?: number;
  expectedRevision: number;
}
```

规则：

- 至少修改一个字段；
- 时区必须是有效 IANA 标识；
- 周起始日必须为 0–6 整数；
- revision 不匹配返回 `REVISION_CONFLICT`；
- 一次命令原子更新字段、revision 和 `updatedAt`。

## 5. API 契约

新增：

```http
PATCH /api/v1/settings/date-time
Idempotency-Key: <uuid>
Content-Type: application/json

{
  "timezone": "Asia/Shanghai",
  "weekStartsOn": 1,
  "expectedRevision": 3
}
```

成功返回完整日期偏好：

```json
{
  "userId": "...",
  "timezone": "Asia/Shanghai",
  "weekStartsOn": 1,
  "revision": 4,
  "updatedAt": "2026-10-09T...Z"
}
```

错误：`400 VALIDATION_ERROR`、`404 RESOURCE_NOT_FOUND`、`409 REVISION_CONFLICT`。相同幂等键重放返回第一次结果。

`bootstrap.user` 增加 `settingsRevision`。设置成功后 Web 直接更新本地 bootstrap 用户，不等待整页刷新。

## 6. Web 交互设计

- 应用栏“设置”按钮打开模态；背景加遮罩但保留可识别的原工作区；
- 桌面使用约 `800 × 680` 双栏；窄屏切换为单栏，分类成为顶部标签；
- 账户页展示只读身份、数据导出和危险区；
- 日期页每行左侧标签、右侧原生 `select`，不设置总保存按钮；
- 修改时禁用两个选择框并显示“正在保存”；成功后显示短暂状态，失败则回滚选择并保留错误；
- `409` 提示“设置已在其他标签页更新”，重新加载 bootstrap，不静默覆盖；
- Escape、遮罩或关闭按钮关闭设置，不改变原 `view/list/item` URL 状态。

时区选择使用浏览器 `Intl.supportedValuesOf("timeZone")`，旧浏览器回退到包含当前值与常用 IANA 时区的列表。显示 IANA ID，避免城市中文名与夏令时规则脱节。

| Web | 设置打开/关闭、即时保存、失败回滚、导出、删除确认 |
| 回归 | `lint`、`typecheck`、相关 unit/integration、Web build |
