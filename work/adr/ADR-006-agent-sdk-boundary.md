# ADR-006：Agent SDK 只负责受限编排

- 状态：已接受
- 日期：2026-08-23

## 背景

项目需要从真实行动生成解释并可持续迭代 Agent 能力，但模型输出不具备数据库权限、数值正确性或租户隔离保证。

## 决策

从 V1 起使用开源 `@openai/agents` SDK，但将其封装在 `packages/agent` 的 `AgentRunner` 实现后。Agent 只能调用六个只读、用户范围内的工具并输出固定 Schema；统计、证据范围、最多 5 个 claim、Guardrail、成本和工具审计由确定性代码验证。Agent 只能提出方向、贡献和记忆候选，不能写任务或长期记忆。

## 后果

- 可在不污染领域层的前提下扩展 Agent 工作流或替换模型供应商。
- 所有模型结果在持久化前经过独立证据校验；失败只影响解释生成。
- 新增写工具必须另立 ADR，并提供明确授权、幂等和人工确认边界。
