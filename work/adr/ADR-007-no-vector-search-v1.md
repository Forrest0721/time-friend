# ADR-007：V1 不引入向量检索

- 状态：已接受
- 日期：2026-08-23

## 背景

周快照的候选证据规模小且已有任务、清单、时间、类型等强结构字段。向量召回会增加索引同步、成本和难以解释的错误关联。

## 决策

V1 使用周期范围、实体类型、清单策略等结构化过滤，辅以 PostgreSQL FTS 与 `pg_trgm`。任何被 Agent 引用的证据都必须存在于冻结快照并通过用户范围校验。

## 后果

- 证据来源可解释，删除和排除策略容易贯彻。
- 跨月语义召回能力受限，但不影响 V1 周轨迹闭环。
- 只有当结构化/全文检索的评测召回率不足、单周期候选显著增长，且匿名基线能证明向量收益时才重新评估。
