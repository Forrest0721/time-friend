# ADR-004：V1 使用 PostgreSQL 与 pg-boss 队列

- 状态：已接受
- 日期：2026-08-23

## 背景

系统需要番茄到时、12 小时提醒、周复盘生成、重试和删号任务。V1 已依赖 PostgreSQL，当前任务规模不需要独立 Redis、Kafka 或 Temporal。

## 决策

使用 pg-boss。API 在业务事务内或事务成功后以稳定 job key 入队；Worker 消费并调用同一领域服务。Job handler 必须幂等，使用实体 revision/input hash 防止旧任务覆盖新状态，并采用有限重试和死信。

## 后果

- 事实与队列共享一个运维组件，减少双写窗口。
- 数据库故障会同时影响业务和队列，因此 Worker 必须支持恢复和积压指标。
- 当任务吞吐显著挤压主库、需要跨服务事件流或长编排补偿时，再评估独立队列/工作流引擎。
