# ADR-008：产品长期记忆独立于 Agent Session

- 状态：已接受
- 日期：2026-08-23

## 背景

聊天/Agent Session 历史不等于用户确认的产品认识：它难以查看、纠正、停用、导出，也无法稳定追踪证据变化和生效周期。

## 决策

长期记忆使用 `memory_candidates` 与版本化 `confirmed_memories`。Agent 只提候选；用户明确确认后才生效。记忆记录来源复盘、有效期、版本和被替代关系，并保存证据依赖；原始证据修改或删除时标记 `review_required`。方向使用独立生命周期模型，Agent 只读取当前有效且已确认的记忆。

## 后果

- 用户拥有可管理、可导出、可审计的产品记忆，而非不可见 prompt 历史。
- 修正生成新版本，不覆写历史；停用和删除不会改写过去复盘。
- 需要维护候选确认、证据依赖失效和版本清理逻辑，但换来可解释的人机边界。
